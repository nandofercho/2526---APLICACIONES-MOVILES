# 📦 Proyecto de Marcación – Frontend & Backend

Este repositorio contiene **dos proyectos principales**, organizados para el desarrollo de una aplicación móvil conectada a un backend.

## 📁 Estructura general

/
├── app-backend/
├── app-mobil/
└── .gitignore

---

## 🐍 Backend – Python (FastAPI)

La carpeta **app-backend** contiene el backend desarrollado en **Python**, usando:

- FastAPI  
- MySQL  
- Autenticación JWT  

Funciones principales:
- Gestión de usuarios y roles  
- Registro de marcaciones  
- Consulta de historial  

Cada carpeta contiene su propio archivo README con instrucciones específicas.

---

## 📱 Frontend – React Native

La carpeta **app-mobil** contiene la aplicación móvil desarrollada en **React Native**, utilizando:

- Expo  
- TypeScript  
- Consumo de API REST  

Funciones principales:
- Inicio de sesión  
- Marcación de asistencia  
- Visualización de historial  
- Perfil de usuario
